# A Pocket of Time

## Add a new post

1. Create a new HTML file inside `posts/`.
2. Add one entry to the `POSTS` list near the bottom of `index.html`:

```js
{title:"Your Post Title", date:"2026-08-28", url:"posts/your-post.html"}
```

That's it. The same entry automatically appears in:
- the bottle-icon post row
- the title under the bottle
- the correct calendar date
- the bottle icon inside that calendar date

Keep `assets/writing-circle.png` and `assets/bottle-post.png` in place.
